配置参数
我们以DeepSeek和Serper搜索为例，演示如何进行参数配置

登录主机中，进入/joyagent-jdgenie目录 (cd /joyagent-jdgenie)

修改genie-backend/src/main/resources/application.yml文件中第12行到第16行的内容，这里默认使用deepseek-chat模型，只需要填写第14行的apikey为自己申请的Deepseek的API KEY

image.png

修改genie-tool/.env中的模型API_KEY，搜素引擎的API_KEY，以及实例的公网IP
这里默认使用deepseek-chat模型(考虑到deepseek-chat模型的token限制，report agent默认使用了deepseek-reasoner模型)和serper搜索引擎，所以只需要配置第1行的DEEPSEEK_API_KEY，第2行的SERVER_IP，以及第32行的SERPER_SEARCH_API_KEY

image.png

修改ui/src/utils/querySSE.ts中第2行的server_ip为实例的公网IP(注意公网IP前要加http://)

image.png

修改ui/vite.config.ts中第6行的server_ip为实例的公网IP
image.png

在/joyagent-jdgenie目录目录下执行./Genie_start.sh，等待出现如下提升，证明Genie服务已经启动
image.png
